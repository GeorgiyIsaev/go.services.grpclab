ClientUnary

Unary — единственный, где весь обмен умещается в одну строку. Нет ни Recv, ни Send, ни CloseAndRecv. Просто «дай мне результат» — и результат приходит.



Ожидаемый вывод клиента
```
2026/10/05 18:00:00 отправляем запрос GetRandom...
2026/10/05 18:00:00 получено число: 7
```
Ожидаемый вывод сервера
```
[Unary] GetRandom → 
```


Тесты Руками:

1. Запустите клиент несколько раз подряд. Каждый раз новое число. Убедитесь, что сервер отвечает мгновенно.

2. Запустите клиент, не подняв сервер. Увидите ошибку через 5 секунд:

text
ошибка вызова: rpc error: code = DeadlineExceeded desc = context deadline exceeded
Это ваш context.WithTimeout. Если бы его не было, клиент ждал бы вечно — а точнее, до таймаута TCP на уровне ОС (может быть 1–2 минуты). Дедлайн в gRPC — обязательная практика.

3. Поставьте дедлайн 1 наносекунду:

go
ctx, cancel := context.WithTimeout(context.Background(), 1*time.Nanosecond)
Сервер физически не успеет ответить — увидите DeadlineExceeded. Так выглядит превышение дедлайна на практике.

4. Через grpcurl:

powershell
grpcurl -plaintext localhost:50051 random.Random/GetRandom
Ответ:

json
{
"value": 7
}
